# A printed master-planned community

An interactive isometric model of a 3D-printed master-planned community. A developer already knows how to build this community. The one change is that the walls are printed.

View it live at https://ibarzabalhec.github.io/printed-community/, or open `index.html` in a browser. It is one self-contained file with no libraries, and it runs on a phone or a laptop.

## What is in it

- A walkthrough in nine steps: land, infrastructure, homes, design, amenities, what the top-selling communities do, rentals and operations, the whole stack, and where printing hits the pro forma.
- Three tours of the same plan, from the builder's, the general contractor's and the hospitality operator's seat.
- A lot map, place cards, day, golden hour and night, weather, and a winter mode in the Calgary setting.
- Randomize builds a new plan. The plan code in the address rebuilds the same plan, so a plan can be shared.
